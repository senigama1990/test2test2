# HyperLex — платформа анализа гиперонимов

HyperLex — веб‑платформа для анализа гиперонимо‑гипонимических отношений в русском и узбекском языках.
Пользователь вводит слово и получает список гиперонимов и гипонимов с визуализацией в виде дерева.

## Структура

- `backend/` — сервер Express с REST‑эндпоинтами.
- `backend/data/` — JSON‑файлы с тестовыми данными.
- `frontend/` — клиент на React.

## Запуск

1. Установите зависимости для сервера и клиента (может потребоваться доступ в интернет):
   ```bash
   cd backend && npm install
   cd ../frontend && npm install
   ```
2. Запустите сервер и клиент:
   ```bash
   cd backend && npm start
   cd ../frontend && npm start
   ```

## Базовые эндпоинты

- `GET /api/search?q=собака&lang=ru`
- `GET /api/word/:id`
- `GET /api/word/:id/tree`
- `GET /api/compare?ru=ru_001&uz=uz_001`
- `GET /api/languages`

Интерфейс и сообщения — на русском языке. Проект можно расширять для графовой визуализации и админ‑панели.
